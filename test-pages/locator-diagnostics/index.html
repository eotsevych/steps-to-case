A unique locator can still depend on row order

The recorder already penalizes duplicate candidates. This experiment asks what happens when its best remaining candidate uses the customer’s position.

  1. Click Edit beside Ben. This captures a locator with the current recorder algorithm.
  2. Click Move Ben to top, then Check captured locator.
  3. Click Reset, then Use stable attributes. Repeat the same steps.

This is a test fixture, not an implemented diagnostics feature. Run it through node scripts/serve-locator-use-case.mjs. The fixture bundles the real selector generator with default settings. Your extension’s custom settings can produce different candidates.
